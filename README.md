# 🖱️ Click Simulator - WPF / C#

Um jogo no estilo *Incremental/Clicker* desenvolvido em C# utilizando a tecnologia WPF (Windows Presentation Foundation).

## 🛠️ Tecnologias Utilizadas

- **C#** (.NET 10)
- **WPF (XAML)** para a interface gráfica
